# Фронтенд

Это фронтенд-приложение для системы учета домашних финансов.

## Описание

Приложение предоставляет интерфейс для управления личными финансами, включая:
- Отслеживание доходов и расходов
- Категоризация транзакций
- Визуализация финансовой статистики
- Управление бюджетом

## Технологии

- React
- TypeScript
- Контекст аутентификации для управления сессиями пользователей

## Бэкенд

Бэкенд приложения разрабатывается на Go. API эндпоинты будут добавлены позже для интеграции с фронтендом.

## Структура проекта

- `/frontend` - исходный код фронтенд-приложения
  - `/src/context` - контексты React (аутентификация и др.)
