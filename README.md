# Фронтенд

Это фронтенд-приложение для системы учета домашних финансов.

## Описание

Приложение предоставляет интерфейс для управления личными финансами, включая:
- Отслеживание доходов и расходов
- Категоризация транзакций
- Визуализация финансовой статистики
- Управление бюджетом

## Технологии

- React
- TypeScript
- Контекст аутентификации для управления сессиями пользователей

## Бэкенд

Бэкенд приложения разрабатывается на Go. API эндпоинты будут добавлены позже для интеграции с фронтендом.

## Структура проекта

- `/frontend` - исходный код фронтенд-приложения
  - `/src/context` - контексты React (аутентификация и др.)

## Запуск проекта

### Требования

- Node.js (версия 18 или выше)
- npm или yarn

### Установка зависимостей

Перейдите в директорию фронтенда и установите зависимости:

```bash
cd frontend
npm install
```

### Запуск в режиме разработки

Для запуска приложения в режиме разработки используйте:

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173` (порт может отличаться в зависимости от конфигурации).

### Сборка для продакшена

Для создания оптимизированной сборки приложения выполните:

```bash
npm run build
```

Собранные файлы будут находиться в директории `dist`.

### Предварительный просмотр продакшен-сборки

Чтобы предварительно просмотреть продакшен-сборку локально:

```bash
npm run preview
```
